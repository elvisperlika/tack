# What's new in Tack 1.0.0

## The first Tack
- **Notes pinned to where you work:** a Finder folder, a browser tab, a Terminal tab, or any app window.
- Browser notes follow the page's URL, Terminal notes follow the tab, so switching tabs never loses them.
- Pin a note to a single window or to the whole app.
- Notes stay inside the window they belong to and follow it as it moves.
- Downloads for Apple Silicon and Intel Macs.
