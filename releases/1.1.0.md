# What's new in Tack 1.1.0

## ✨ What's New
- **Markdown as you type:** headings, **bold**, *italic*, `code` and ~~strikethrough~~ format themselves.
- Lists and checkboxes are drawn as real bullets and boxes.
- New notes start in a default colour.

## 🐛 Fixes
- Notes keep their place more accurately while you move and resize windows.
