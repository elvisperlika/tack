# What's new in Tack 1.11.0

## ✨ What's New
- **This page.** Each release now tells you what changed, right here. Find it again with ✨ in the dashboard pill.
- **Notes from AI agents.** With the `/tack` skill, an agent like Claude Code can leave a note on the PDF, page or folder it worked on.

## 🐛 Fixes
- Notes now stick to Electron apps such as Notion.
- Clicking a document note in the dashboard opens that document, not just its app.
- The pointer stays an arrow over the pill, instead of switching to the text cursor.
