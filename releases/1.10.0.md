# What's new in Tack 1.10.0

## ✨ What's New
- **A calmer pill:** it grows first, then its dots pop in together, and the dot under the cursor zooms.
- Deleting a note asks for confirmation in the pill instead of an alert.
- New notes start titled "New note".
- The line you're typing stays in view.
- The dashboard opens centred on the note it grows from, on a neutral off-white background.
